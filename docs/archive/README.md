# Archiwum wcześniejszych koncepcji

Sześć plików z katalogu głównego przeniesiono do jednego podkatalogu, zachowując treść bajtowo i ich wzajemne względne odnośniki. [Manifest](manifest.json) zawiera oryginalne nazwy oraz SHA-256. Walidator dokumentacji wykrywa zmianę archiwalnego pliku.

**Archiwum jest historyczne, nie normatywne.** Zawiera dawne propozycje, nakładające się plany i parametry; nie należy ich traktować jako aktualnych ustaleń lub wykonanej pracy. Źródła obowiązujące są wskazane w [głównym README](../../README.md).
